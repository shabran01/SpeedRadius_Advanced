📡 PPPoE Remote IP

Static IP Assignment for PPPoE Customers — SpeedRadius Admin Guide

📌 What is Remote IP?

The Remote IP field on the Customer profile (Add / Edit) assigns a fixed (static) IP address to a specific PPPoE customer's connection on the MikroTik router.

When a PPPoE customer connects, the router normally picks an IP dynamically from a shared pool. Filling in Remote IP overrides this — that customer will always receive the exact IP you specify, every time they connect.

ℹ️ Field Location Admin Panel → Customers → Add/Edit Customer → PPPOE section → Remote IP

✅ When to Use It

  • Customer runs a server, CCTV system, or web application that needs a fixed address
  • You need to apply specific firewall rules targeting one customer by IP
  • Customer requires remote access (VPN, RDP) to equipment at their premises
  • You want to apply a custom bandwidth queue tied to a specific IP
  • Integrations or third-party systems reference the customer by a fixed IP address
✅ Most customers don't need this Leave Remote IP blank for regular Hotspot or standard PPPoE customers. The router will assign a dynamic IP from its pool automatically.

⚙️ How It Works

MikroTik Native PPPoE

SpeedRadius pushes the Remote IP value to the MikroTik router as a PPP Secret remote-address. When the customer authenticates, the router sees the remote-address configured on their secret and assigns that IP directly.

FreeRADIUS

The Remote IP is sent as the Framed-IP-Address RADIUS attribute in the Access-Accept response. The NAS device (MikroTik or other) then assigns that IP to the PPPoE session.

⚠️ Important compatibility note The PPPoE Username override field does not work with FreeRADIUS MySQL. The Remote IP field works with both MikroTik-native PPPoE and FreeRADIUS.

🛠️ How to Assign a Static IP to a Customer

  1. Go to Admin Panel → Customers and open the customer's profile (Edit).
  2. Scroll down to the PPPOE section.
  3. Enter the desired static IP address in the Remote IP field (e.g. 192.168.100.50).
  4. Click Save Changes. SpeedRadius will push the change to the router immediately.
  5. Ask the customer to reconnect their PPPoE session for the new IP to take effect.
⛔ Avoid IP conflicts Make sure the IP you assign is outside the router's dynamic IP pool range, or reserve it in the pool, to prevent the same address being given to another customer simultaneously.

🗑️ How to Remove a Static IP (Back to Dynamic)

Simply clear the Remote IP field in the customer's Edit page and save. On the next reconnect, the router will assign a dynamic IP from the pool as normal.

❓ Frequently Asked Questions

Can I assign the same IP to two customers?

Technically the system won't block it, but it will cause an IP conflict on the router — only one customer will get connectivity. Always assign unique IPs.

Does Remote IP work for Hotspot customers?

No. Remote IP only applies to PPPoE customers. Hotspot sessions use MAC-based or username-based IP assignment configured on the router's hotspot profile.

What happens if the IP I set is already in use on the network?

The PPPoE session will still connect, but there will be an IP conflict and connectivity will be unreliable. Always check your network's IP plan before assigning a static IP.

Can a customer with a static IP be auto-renewed by the system?

Yes. Auto-renewal works independently of the Remote IP setting. The IP assignment persists across renewals.
