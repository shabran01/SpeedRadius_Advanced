SpeedRadius Plugin

📱 SmSGate Gateway

Send SMS messages through your own Android phone using the sms-gate.app Cloud API — no third-party SMS subscription required.

📋 Overview

SmSGate is a custom SpeedRadius plugin that connects your billing system to an Android phone via sms-gate.app — a free, open-source Android SMS gateway app. When SpeedRadius needs to send a notification (expired package, payment receipt, reminder), it calls the sms-gate.app Cloud API which relays the message to your Android phone, and the phone sends it as a real SMS using your SIM card.

✅ Free to use No monthly fees. Costs only your phone's airtime or SMS bundle. No registration or account needed on sms-gate.app.

⚙️ How It Works

  1. SpeedRadius triggers a notification (e.g. customer's PPPoE package expired)
  2. The SmSGate plugin fires and sends a POST request to https://api.sms-gate.app/3rdparty/v1/message with the phone number and message text, authenticated with your username and password
  3. The sms-gate.app cloud server receives the request and queues it for your device
  4. The app on your Android phone picks up the queued message (as long as it has internet)
  5. The phone sends the SMS using your SIM card to the customer's number
  6. Status (sent/failed) is logged in the tbl_sms_logs table and shown on the plugin dashboard

Duplicate Protection

The plugin uses the built-in SMSLock helper along with a 5-minute database check to prevent the same message being sent twice to the same number within a short period. This protects against double-billing notifications during cron retries.

🛠️ Setup & Configuration

  1. Install the app on your Android phone
    Download from sms-gate.app or directly from GitHub releases. Enable Cloud server toggle. Enable Start on boot. Confirm app shows ONLINE.
  2. Select SmSGate as the active gateway
    Admin Panel → Settings → App Settings → SMS Gateway dropdown → select SmSGate → Save.
  3. Enter your credentials
    Admin Panel → SmSGate Gateway (in left menu) → Configuration tab
    • Username — shown on the app's Home screen (e.g. HSHN-U)
    • Password — shown on the app's Home screen
    • Device ID — shown on the app's Home screen (optional, but recommended if you have one device)
  4. Send a test SMS
    Go to SmSGate Gateway → Dashboard → enter a phone number → click Send Test. If successful, the result shows "✓ Sent successfully!" and the SMS arrives on the target phone.
⚠️ Phone must stay online Keep the Android phone connected to WiFi and plugged in to charge at all times. Cloud mode requires the phone to have an internet connection to receive and send messages. If the phone is offline temporarily, the cloud server queues the message and delivers it when the phone reconnects.

🔌 API Reference

Endpoint Used

POST https://api.sms-gate.app/3rdparty/v1/message
Authorization: Basic (username:password)
Content-Type: application/json

Request Body

{
  "message":      "Hello customer, your package has expired.",
  "phoneNumbers": ["+254712345678"],
  "deviceId":     "tN6WX8KrpxzY5gkPuXWP-"  // optional
}

Response

// Success — HTTP 202 Accepted
{ "id": "msg_abc123", "state": "Pending" }

// Failure — HTTP 4xx / 5xx
{ "message": "Unauthorized" }

📨 Notifications Sent Through SmSGate

Once configured as the active SMS gateway, SmSGate handles all of these notification types:

EventPPPoEHotspotChannel
Package expired ✅ Sent ❌ Blocked (by setting) SMS + WhatsApp (both)
Payment / recharge received ✅ Sent ✅ Sent SMS + WhatsApp (both)
Expiry reminder (7, 3, 1 day) ✅ Sent ❌ Blocked (by setting) SMS + WhatsApp (both)
Welcome message (on add customer) ✅ If enabled ✅ If enabled SMS / WA / Email (admin choice)
ℹ️ WhatsApp notifications SmSGate handles the SMS channel only. WhatsApp notifications are handled separately by the WhatsApp gateway configured in Admin → Settings → WhatsApp.
