3 Configuration Steps

What each section of the script does, in order.

Step 0 — Cleanup

Remove Previous Configuration

Removes any existing bridge ports, hotspot server, hotspot profile, DHCP server, IP pool, and IP address that match this setup. Uses [find ...] so if nothing exists it silently skips — making the script safe to re-run on any router state.

Step 1 — Admin User

Create Admin Account

Adds user speedradius with full group permissions. This is the management account for the router — tagged "DONT DELETE" in comments.

Step 2 — Bridge

Create Hotspot-Server Bridge

Creates a software bridge called Hotspot-Server and assigns ether2 and ether3 as member ports. Both ports now behave as one logical LAN segment.

Step 3 — IP Address

Assign Gateway IP

Sets 10.0.0.1/22 on the bridge. This becomes the default gateway for all hotspot clients. The /22 subnet provides 1022 usable client addresses.

Step 4 — DHCP Server

Auto-assign Client IPs

Creates IP pool 10.0.0.2 – 10.0.3.254, a DHCP server on the bridge, and a network entry advertising gateway 10.0.0.1 and DNS servers 8.8.8.8 / 1.1.1.1.

Step 5 — DNS

Enable DNS Resolver

Enables the router's built-in DNS resolver and allows remote requests from clients. Uses Google and Cloudflare DNS upstream.

Step 6 — NAT

Masquerade LAN Traffic

Adds a srcnat masquerade rule on ether1. All client traffic leaving the LAN appears to come from the router's WAN IP — standard internet sharing setup.

Step 7 — Hotspot Profile

Configure Authentication Methods

Creates profile hsprof1 with the hotspot portal reachable at hotspot.wifi. Enables HTTP-CHAP, HTTP-PAP, HTTPS, MAC cookie, and MAC auth. RADIUS is disabled (local auth only).

Step 8 — Hotspot Server

Start the Hotspot

Creates and enables hotspot server hotspot1 on the Hotspot-Server bridge using the profile and DHCP pool defined above.

Step 9 — Walled Garden

Allow Portal Access Before Login

Adds hotspot.wifi to the walled garden so unauthenticated clients can reach the login page without being blocked.

Step 10 — Hotspot User

Create Local Login Account

Adds a hotspot user speedradius with password 1234 on the default profile. This allows immediate login testing without RADIUS or external authentication.

Step 11 — Firewall

Disable Drop & Fasttrack Rules

Disables all firewall filter rules with action=drop (rows 2, 5, 10, 11) and action=fasttrack-connection (row 8). This prevents default defconf rules from blocking or bypassing hotspot traffic.

4 Full Script

The complete hotspot.rsc file as deployed on the server.

ℹ️

Line endings The file is saved with Unix LF (\n) line endings — NOT Windows CRLF (\r\n). RouterOS will fail with a syntax error if the file has CRLF endings.

hotspot.rsc — RouterOS Script LF · UTF-8 
# CLEANUP (safe to run on fresh or partial config)
/interface bridge port remove [find interface=ether2]
/interface bridge port remove [find interface=ether3]
/interface bridge remove [find name=Hotspot-Server]
/ip hotspot remove [find name=hotspot1]
/ip hotspot profile remove [find name=hsprof1]
/ip dhcp-server remove [find name=dhcp1]
/ip pool remove [find name=hotspot-pool]
/ip address remove [find address="10.0.0.1/22"]

# Admin user
/user add name=speedradius password="KWEYU01@@" group=full comment="DONT DELETE"

# Bridge
/interface bridge add name=Hotspot-Server
/interface bridge port add bridge=Hotspot-Server interface=ether2
/interface bridge port add bridge=Hotspot-Server interface=ether3

# IP Address
/ip address add address=10.0.0.1/22 interface=Hotspot-Server

# DHCP
/ip pool add name=hotspot-pool ranges=10.0.0.2-10.0.3.254
/ip dhcp-server add name=dhcp1 interface=Hotspot-Server address-pool=hotspot-pool disabled=no
/ip dhcp-server network add address=10.0.0.0/22 gateway=10.0.0.1 dns-server=8.8.8.8,1.1.1.1

# DNS
/ip dns set allow-remote-requests=yes servers=8.8.8.8,1.1.1.1

# NAT
/ip firewall nat add chain=srcnat out-interface=ether1 action=masquerade

# Hotspot profile
/ip hotspot profile add name=hsprof1 hotspot-address=10.0.0.1 dns-name=hotspot.wifi login-by=http-chap,http-pap,https,mac-cookie,mac mac-auth-password=1234 use-radius=no

# Hotspot server
/ip hotspot add name=hotspot1 interface=Hotspot-Server address-pool=hotspot-pool profile=hsprof1 disabled=no

# Walled garden
/ip hotspot walled-garden add dst-host=hotspot.wifi comment="Hotspot Login"

# Hotspot user
/ip hotspot user add name=speedradius password=1234 profile=default

# Disable firewall drop & fasttrack rules
/ip firewall filter set [find action=drop] disabled=yes
/ip firewall filter set [find action=fasttrack-connection] disabled=yes

5 Troubleshooting

Errors encountered during setup and how they were resolved.

6 Deployment

How to deploy and re-run the script on any MikroTik router.

Option A — Remote fetch (recommended)

MikroTik Terminal 
/tool fetch url="https://speedcomwifi.xyz/hotspot.rsc" mode=https dst-path=hotspot.rsc; /import file-name=hotspot.rsc

Option B — Direct paste

Copy the full script from Section 4 and paste it line-by-line into the MikroTik terminal or Winbox terminal.

⚠️

Important — Line endings If you edit hotspot.rsc on Windows, always save with LF (Unix) line endings. In VS Code, click the CRLF indicator in the bottom-right status bar and switch to LF before saving.

ℹ️

Script is idempotent The cleanup block at the top means you can safely run this script on a router that already has a partial or complete hotspot config — it will reset and reapply everything cleanly.
