## ✨ What is SpeedRadius?

**SpeedRadius** is a complete, API-based billing system for **Hotspot**, **Static IP** and **PPPoE** on MikroTik — powered by PHP and the MikroTik API. It is designed for ISPs and WISPs who need a reliable, feature-rich billing platform that just works.

---

## ⚙️ System Requirements

**Minimum requirements:**

- ✅ Linux or Windows OS (Linux recommended)
- ✅ PHP **7.4+**
- ✅ PDO & MySQLi support
- ✅ PHP-GD2, PHP-CURL, PHP-ZIP, PHP-Mbstring
- ✅ MySQL 4.1+
- ✅ Can run on a Raspberry Pi

> ⚠️ Cron jobs are much easier to set up on **Linux** — we recommend it.
